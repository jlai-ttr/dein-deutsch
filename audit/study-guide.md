## Practice Order

Start with rules where engine agrees (✅), then tackle mismatches (⚠️), then rules without engine rule (🚫):

1. **Supreme first** (rules 1-3): -chen/-lein, male humans, metals. Learn by heart.
2. **High-confidence structural** (rules 4-15): -ung, -heit, -keit, -ion, -in, -ismus, -eur, -or.
3. **Phonetic blocks** (rules 25-66): drill by ending.
4. **Foreign loans** (rule 67): most default -s plural.
5. **Compound tier** (rule 68): last element wins.
